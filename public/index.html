Google Workspace MCP Server

Model Context Protocol (MCP) server deployed on Vercel connecting AI assistants to Gmail and Google Docs.

Service Endpoints

MCP Protocol Endpoint: https://mcpservergroww.vercel.app/mcp

Health Check: /health

Exposed Tools:

  • send_email — Send plain-text emails via Gmail API.
  • append_to_google_doc — Append plain text to an existing Google Doc without overwriting prior content.

AI Assistant Client Configuration

Add this endpoint to your client configuration (Cursor, Antigravity, Claude Desktop):

{
  "mcpServers": {
    "google-workspace": {
      "url": "https://mcpservergroww.vercel.app/mcp"
    }
  }
}
